Learn Polymorphism

Explore the essential concepts of C++ polymorphism with simple examples.

01 / BASICS

Function Overloading

Multiple functions share a name but use different parameter lists.

int add(int a, int b) {
    return a + b;
}

double add(double a, double b) {
    return a + b;
}
COMPILE-TIME
02 / OPERATORS

Operator Overloading

Give operators such as + custom behaviour for user-defined types.

class Number {
public:
    int value;

    Number(int n) : value(n) {}

    Number operator+(const Number& n) {
        return Number(value + n.value);
    }
};
COMPILE-TIME
03 / ADVANCED

Virtual Functions

Use a base pointer or reference to call an overridden derived function.

class Animal {
public:
    virtual void sound() {
        cout << "Animal";
    }
};

class Dog : public Animal {
public:
    void sound() override {
        cout << "Bark";
    }
};
